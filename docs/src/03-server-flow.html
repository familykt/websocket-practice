現状の制限
Ping / Pong を扱わない長時間アイドルの接続は検知できない
分割フレーム（Continuation）に未対応FIN = 0 のメッセージは結合しない
Origin を検証しないローカルでの学習用途に限定
Close 以外の opcode を区別しないBinary / Ping も文字列として扱う
実装: Ruby 標準ライブラリのみ（socket / digest / base64）ここまでが「仕様を自分の手で動かした」範囲
